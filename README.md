# Breeze Valley Channel Manager

Custom hotel channel manager for Breeze Valley, Panchgani/Mahabaleshwar, Maharashtra, India.

## Current Phase

**Phase 0 — Architecture and Foundation**

The first product is an internal channel manager for OTA inventory, rates, reservations, cancellations, and modifications.

Target channels:

- Agoda
- MakeMyTrip
- Goibibo
- Booking.com
- Airbnb

No production OTA integrations are implemented yet.
